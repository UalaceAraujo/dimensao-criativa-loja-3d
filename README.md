# Dimensão Criativa - Loja Virtual de Impressão 3D

Site institucional e vitrine virtual para uma loja de Manufatura Aditiva e Impressão 3D, desenvolvido com HTML, CSS e JavaScript puro (Vanilla JS).

## 🎯 Sobre o projeto

Landing page comercial completa, com identidade visual própria e um canal de atendimento via WhatsApp com geração automática de mensagens personalizadas — pensado para reduzir fricção entre a visita ao site e o primeiro contato comercial.

## ✨ Funcionalidades

- **Vitrine de produtos** em carrossel horizontal com rolagem contínua, exibindo peças impressas em 3D (esculturas, chassis, luminárias, troféus, entre outros).
- **Popup comercial** discreto no canto da tela, que se expande ao aproximar o mouse, com selos de confiança.
- **Página de atendimento via WhatsApp** (`whatsapp.html`) com:
  - Cards de departamentos (orçamento, projetos personalizados, dúvidas sobre pedido, suporte técnico);
  - Formulário dinâmico que monta a mensagem em tempo real;
  - Simulador visual de chat, no estilo do próprio WhatsApp, mostrando a prévia da mensagem antes do envio;
  - Botão que abre o WhatsApp Web/App já com a mensagem pronta (via `wa.me`).
- **Identidade visual personalizada**, com paleta de cores própria (azul cobalto, rosa magenta, dourado, roxo e ciano).
- Layout **responsivo**, construído com CSS puro (Flexbox/Grid).

## 🛠️ Tecnologias

- HTML5
- CSS3 (variáveis CSS, Flexbox/Grid, animações)
- JavaScript (manipulação de DOM, geração dinâmica de conteúdo, integração com API do WhatsApp)
- Google Fonts (Montserrat, Orbitron)

## ▶️ Como executar

Não há dependências ou build necessários. Basta abrir o arquivo `index.html` em qualquer navegador, ou servir a pasta com uma extensão como *Live Server* (VS Code).
